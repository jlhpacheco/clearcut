# ClearCut Private Agent Service

This is the private Google ADK agent service for ClearCut, providing automated research and clearance-preparation capabilities.

## Features

- Built on the Google Agent Development Kit (ADK) and Google GenAI SDK.
- Integrates with the Parallel Search API v1 for parallelized, high-quality web searches.
- Serves findings, coordinates background research flows, and validates contracts with strict Pydantic schemas.
